## Overview

Giay Chung Nhan PDP is a certificate verification website built to make certificate lookup clear, fast, and accessible from the browser. The platform focuses on helping users search for certificate records and review verification information through a clean web interface.

The project prioritizes trust, readability, and simple user flow because certificate verification needs to feel direct and reliable.

## Key Features

- **Certificate Lookup**: Search and view certificate information through a focused lookup interface.
- **Verification Flow**: Present certificate details in a way that is easy to scan and verify.
- **Public Website Experience**: Provide a simple web experience for users who need to access certificate information online.
- **Responsive Screens**: Support a clean viewing experience across common desktop and mobile screen sizes.

## My Role

I worked on the frontend implementation, focusing on page layout, interface structure, responsive styling, and turning the certificate verification flow into a usable web experience.

## Technologies

- **React / Next.js**: Used to build the web interface and page structure.
- **TypeScript**: Used to keep UI logic safer and easier to maintain.
- **Responsive CSS**: Used to make the lookup experience work across screen sizes.
