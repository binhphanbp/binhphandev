## Overview

UpNext is a recruitment website design concept created in Figma. The project explores how a hiring platform can present job opportunities, company information, and candidate-focused actions in a clean and approachable interface.

The design direction focuses on clarity, trust, and fast scanning, which are important for both job seekers and employers in a recruitment experience.

## Key Features

- **Homepage Experience**: A landing page structure that introduces the recruitment platform and guides users toward job discovery.
- **Job Discovery Flow**: UI sections designed to help candidates browse opportunities and understand key job information quickly.
- **Employer Presentation**: Layout patterns for showing company value, hiring details, and platform credibility.
- **Responsive Visual System**: A consistent interface direction prepared for web layouts and future implementation.

## My Role

I designed the UpNext interface in Figma, focusing on layout structure, visual hierarchy, page composition, and usability for a recruitment website experience.

## Tools

- **Figma**: Used for UI design, layout exploration, component organization, and visual presentation.
